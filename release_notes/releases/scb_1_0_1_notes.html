Scarabaeus 1.0.1 Release Notes#

Changelog#

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

[Unreleased]#

Added#

  • EphemerisCache:

    • Rust module that saves the Chebyshev polynmials representing the trajectory of a body or bodies.

    • Computes third body accelerations using its cached ephemerides.

  • Update Propagator to return a Trajectory object as solution.

  • More descriptive error handling:

    • SPKNotLoadedError: raised when ThreeBodyGravity is unable to query the requested third bodies due to no loaded S(pacecraft) and P(lanet) Kernel.

Changed#

  • ThreeBodyGravity:

    • Caches non-propagated bodies by evaulating their SPK Chebyshev polynomials directly inside the integrator using EphemerisCache.

    • Notable performance improvements from EphemerisCache for non-propagated third body accelerations.

Deprecated#

  • StateArray.from_components()

[1.1.1] - 2026-07-03#

Added#

  • Keep a changelog functionality.

Fixed#

  • More lenient Python versioning in pyproject.toml.

[1.0.0] - 2026-06-01#

Added#

  • See Scarabaeus 1.0 Release Notes.
