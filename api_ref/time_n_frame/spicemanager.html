SpiceManager#

class SpiceManager#

Bases: object

Unified interface to NASA SPICE via SpiceyPy.

Provides static utility methods for loading/unloading SPICE kernels, querying body states and positions, converting between time systems, resolving body and frame identifiers, and computing geometric quantities (light time, ground-station visibility, etc.).

All methods that return physical quantities wrap their output in ArrayWUnits or ArrayWFrame to carry units and frames explicitly.

Notes

SpiceManager is a pure-static class; it holds no instance state. Configuration is done through class-level attributes:

  • kernel_list — list of currently loaded kernel paths.

  • kernel_folder — default folder scanned for scenario kernels.

  • poly_interp_deg — polynomial degree for state interpolation.

classmethod get_STMs(trgt_bdy: str | Body, epoch_time: float, reference_frame: str | Frame, obsvr_bdy: str | Body, folder_path_override: str = None, sidecar_path=None) → ndarray#

Retrieve or interpolate the State Transition Matrix (STM) at a given epoch.

Reads the candidates sidecar_files() resolves from sidecar_path — an SPK, a file, a folder, or several of them — and takes the first whose body_ID, origin_ID, and reference_frame match the supplied arguments. If epoch_time equals a stored epoch the corresponding STM is returned directly. Otherwise element-wise linear interpolation is performed between the two bracketing epochs.

A sequence sidecar stores one STM block per leg, each on that leg’s own grid. The STM is then taken from the first leg whose span holds epoch_time, so an epoch on the boundary between two legs reads the end of the earlier one.

Parameters:
trgt_bdystr or Body

Target body whose STMs are requested.

epoch_timefloat

TDB epoch (seconds past J2000) at which to retrieve/interpolate the STM.

reference_framestr or Frame

Reference frame recorded in the STM JSON file.

obsvr_bdystr or Body

Observer (origin) body recorded in the STM JSON file.

folder_path_overridestr, optional

Deprecated alias for sidecar_path, kept working for callers that pass a folder. Defaults to None.

sidecar_pathstr or os.PathLike or iterable, optional

Where to look for the sidecar: an SPK, a file, a folder, or an iterable of those — see sidecar_files(). Defaults to None.

Returns:
STMnumpy.ndarray

Shape (n, n) State Transition Matrix evaluated at epoch_time, n being the size of the state it was propagated with.

Raises:
SidecarNotFoundError

If no matching STM sidecar is found in any location searched.

ValueError

If epoch_time lies outside the stored time span, or outside every leg’s span for a sequence sidecar.

classmethod get_elevation_angle(target: str, et, station: str = 'DSS-14', abcorr: str = 'LT+S') → float#

Compute the elevation angle of a target body as seen from a DSN ground station using SPICE.

This method uses the SPICE toolkit to calculate the elevation angle of a target relative to a Deep Space Network (DSN) ground station. The calculation is performed in the station’s local topocentric frame (e.g., DSS-14_TOPO), where the convention is X = East, Y = North, and Z = Up.

Parameters:
targetstr

The name or NAIF ID of the target body. Examples: "MRO" or "-74".

etfloat

Ephemeris time at which to compute the elevation angle.

stationstr

The DSN ground station name or NAIF ID used as the observer. Must match the identifiers defined in the loaded SPICE kernels. Defaults to "DSS-14".

abcorrstr, optional

Aberration correction to apply when computing the geometry. Examples: - "NONE": No corrections. - "LT": Light-time correction only. - "LT+S": Light-time + stellar aberration correction (default).

Returns:
elevation_angleArrayWUnits

The elevation angle of the target relative to the local horizon at the specified DSN station, expressed in radians (or the units defined by cls._spc_angle_units). Positive values indicate the target is above the horizon, while negative values indicate it is below.

Notes

  • The station’s topocentric frame (e.g., DSS-14_TOPO) must be defined in the loaded SPICE kernels.

  • The axis convention for topocentric frames is assumed to be: X = East, Y = North, Z = Up.

  • To obtain azimuth as well, use atan2(East, North) in the same frame.

  • Requires SPICE kernels for:

    • DSN station locations and frames.

    • Target body ephemerides.

    • Leapseconds (LSK).

classmethod get_parameters(trgt_bdy: str | Body, epoch_time: float | EpochArray, reference_frame: str | Frame, obsvr_bdy: str | Body, folder_path_override: str = None, per_parameter: bool = False, sidecar_path=None)#

Retrieve and interpolate estimated parameters from a companion JSON file.

Reads the candidates sidecar_files() resolves from sidecar_path — an SPK, a file, a folder, or several of them — and takes the first whose body_ID, origin_ID, and reference_frame match the supplied arguments, at the top level or in any leg. If the file contains a multi-leg sequence, the leg whose epochsTDB interval contains epoch_time is selected. Within each leg (or in the flat, non-sequence case) the stored parameter time series is fitted with a polynomial of degree cls.poly_interp_par_deg and evaluated at epoch_time.

Parameters:
trgt_bdystr or Body

Target body whose parameters are requested.

epoch_timefloat or EpochArray

TDB epoch (seconds past J2000) at which to evaluate the parameters.

reference_framestr or Frame

Reference frame recorded in the JSON file.

obsvr_bdystr or Body

Observer (origin) body recorded in the JSON file.

folder_path_overridestr, optional

Deprecated alias for sidecar_path, kept working for callers that pass a folder. Defaults to None.

per_parameterbool, optional

Return a {name: ArrayWUnits} mapping instead of the stacked vector. Defaults to False.

sidecar_pathstr or os.PathLike or iterable, optional

Where to look for the sidecar: an SPK, a file, a folder, or an iterable of those — see sidecar_files(). When None (default), cls.kernel_folder is used if set; otherwise falls back to <cwd>/data/kernels/scenario.

Returns:
parametersArrayWUnits or dict of str to ArrayWUnits

By default an ArrayWUnits holding the stacked parameter vector, always — the return type does not vary with the contents of the file.

Its units are the shared units when every parameter of the body agrees, which is the usual case. A body’s parameters need not agree, though: solving for a delta-v (km/s) alongside a maneuver-epoch correction (sec) is ordinary. No single unit then describes the stack, so it is reported dimensionless rather than mislabelled with whichever unit came first, and per_parameter is the way to recover what each column actually is.

With per_parameter=True, a {name: ArrayWUnits} mapping instead, each entry carrying its own units.

Raises:
SpiceManager.SidecarNotFoundError

If no matching sidecar is found; the message lists every location searched.

ValueError

If the sidecar is malformed (e.g. a leg’s parameters entry), or if epoch_time does not fall within any leg’s time span.

Warns:
RuntimeWarning

If more than one matching sidecar is found; the most recently modified file is used.

classmethod get_sep_angle(target: str, et, station: str = 'DSS-14', abcorr: str = 'LT+S') → float#

Compute the Sun–Earth–Probe (SEP) angle of a target body as seen from a DSN ground station.

The SEP angle is defined as the angle at the observer (DSN station) between the vector pointing to the Sun and the vector pointing to the spacecraft (target). This is the standard “solar elongation angle” used in mission operations to assess geometry for radiometric tracking and solar corona effects.

Parameters:
targetstr

The name or NAIF ID of the target body. Examples: "OSIRIS-REX" or "-64".

etfloat

Ephemeris Time (seconds past J2000 TDB) at which to compute the SEP angle.

stationstr, optional

DSN ground station name or NAIF ID used as the observer. Must match the identifiers defined in the loaded SPICE kernels. Default is "DSS-14".

abcorrstr, optional

Aberration correction to apply when computing the geometry. Examples: - "NONE": No corrections. - "LT": Light-time correction only. - "LT+S": Light-time + stellar aberration correction (default).

Returns:
sep_angleArrayWUnits

The SEP angle in radians (or converted via cls._spc_angle_units). Larger angles correspond to better tracking geometry (target farther from the Sun as seen from Earth).

Notes

  • Requires SPICE kernels for:

    • DSN station locations (SPK + topocentric frame definitions).

    • Target body ephemerides (SPK).

    • Solar system ephemerides (SPK).

    • Leapseconds (LSK).

  • This angle is distinct from elevation angle (target above station horizon). SEP measures angular separation from the Sun, not from the horizon.

  • Often used to set operational limits during solar conjunctions.

classmethod sidecar_files(location=None, kind: str = 'parameters') → list[str]#

List the sidecar files a lookup would read, in the order it reads them.

Sidecars are found by where they are, not by a folder layout this library imposes, so location can be whatever handle the caller happens to hold:

  • an SPK (.bsp) — the sidecars written beside it are read first (<base>_parameters.json and friends), then anything else in the same folder, which covers a run whose sidecars are shared under a different basename;

  • a file — read as-is, whatever it is called;

  • a folder — the files in it whose names carry this library’s suffix for kind come first, then any other .json / .pkl, so a folder following someone else’s naming still resolves;

  • an iterable of any of the above — searched in the given order, for payloads split across locations;

  • None — kernel_folder when set, then <cwd>/data/kernels/scenario.

Locations that do not exist are skipped rather than raised on: the callers report every location they consulted when a lookup finds nothing, which is more useful than failing on the first missing one.

Parameters:
locationstr or os.PathLike or iterable, optional

Where to look, as described above. Defaults to None.

kindstr, optional

Which payload is wanted — 'parameters', 'stms', 'settings', or 'mass_profile'. Only sets which suffixes are preferred. Defaults to 'parameters'.

Returns:
list of str

Absolute paths of existing candidate files, most specific first, without duplicates.

Write a segment of type 13 to an SPK file.

Type 13 stores the same (epoch, position, velocity) records as type 9, in the same number of bytes, but interpolates them with Hermite polynomials that use the sampled velocities as derivative constraints on the position curve. The returned velocity is then the exact derivative of the returned position, and at degree_poly=3 the two-node window makes the interpolant C1-continuous across every node, removing the jumps a shifting type-9 Lagrange window produced at each node crossing.
