MeasurementScheduler#

class MeasurementScheduler(target: Spacecraft | Body = None, start: str | float | EpochArray = None, end: str | float | EpochArray = None, cadence: ArrayWUnits = None, elevation_mask: ArrayWUnits | float = 10.0, frame: Frame = J2000 (0 - SOLAR SYSTEM BARYCENTER), noisy: bool = False, output_dir: str = None, fmt: str = 'json', pass_gap: ArrayWUnits = None)#

Bases: object

Builds measurement models and their synthetic observations from tracking requests.

A request is an observer (a DSN station name such as "DSS-14", a GroundStation, a Camera or a Spacecraft), a measurement type and a tracking window: start, end and cadence. Every request carries its own window, so one scheduler holds, side by side, range from Goldstone every ten minutes over three days, Doppler at one minute over a single pass and OpNav images every hour over a week, and hands them all to a filter as one MeasurementSpec. Whatever is given to the constructor (target, window, elevation mask, …) is only the default for requests that do not set their own.

A window can recur, with a period of its own or on the UTC calendar:

  • pass_cadence / pass_duration (and an optional pass_offset), all ArrayWUnits times, keep slots of pass_duration starting every pass_cadence from start + pass_offset, at any period: an OpNav batch of 30 minutes every 6 hours is pass_cadence=ArrayWUnits(6, hr), pass_duration=ArrayWUnits(30, min), one image per orbit pass_cadence=orbit_period, pass_duration=cadence;

  • weekdays keeps only some days of the week;

  • hours keeps one or several UTC time-of-day ranges within each day, so two passes a day are hours="02:00-04:00, 14:00-16:00";

  • passes_per_day keeps the first n tracking passes that start on each UTC day.

They combine, so “one pass every Monday from today to next month” is schedule("DSS-14", "RangeIdeal", start=date.today(), end=..., cadence=ArrayWUnits(10, min), weekdays="Mon", passes_per_day=1).

For every request the scheduler

  1. builds the epoch grid [start, end) at the request’s cadence (only inside the slots and days / hours kept by the recurrence),

  2. keeps the epochs at which the observer can see the target (elevation above the mask for a ground station, target inside the field of view for a camera),

  3. builds the measurement model named by the measurement type,

  4. writes the synthetic observations to disk and reads them back,

  5. returns a MeasurementSpec ready for a filter.

The measurement type is the name of the model class that is built: "RangeIdeal", "RangeRateIdeal", "DopplerIdeal", "DiffOneWayRangeIdeal" (radiometric, from a ground station), "CentroidingIdeal" (from a camera) or "AngularIdeal" (from a spacecraft or station). Case and separators do not matter ("doppler_ideal" works) and the class itself can be passed. The short spellings "range", "range_rate", "doppler", "dor", "opnav", "angular", … (MEASUREMENT_TYPE_ALIASES) always mean the ideal model. The real TRK-2-34 models ("DopplerReal", "SequentialRangingReal") raise MeasurementScheduler.RealModelNotSupportedError: their observable is computed from per-epoch tracking data (ramp tables, count times, turnaround ratios, station delays) that cannot be synthesised yet.

Parameters:
targetSpacecraft or Body, optional

Default body being tracked or imaged. Its SPICE name must resolve over the requested windows (an SPK for it must be loaded). Requests can name their own target (the imaged body for OpNav). Defaults to None.

startstr, float or EpochArray, optional

Default first epoch of a request. Calendar strings are UTC and parsed with cal2et(); floats are TDB seconds past J2000; a datetime.date / datetime.datetime is UTC; an EpochArray is taken at its first epoch. Defaults to None.

endstr, float or EpochArray, optional

Default end of a request, same conventions as start (an EpochArray is taken at its last epoch). Grids are half open: end itself is not included. Defaults to None.

cadenceArrayWUnits, optional

Default spacing between consecutive measurements, a single ArrayWUnits time such as ArrayWUnits(10, min). Defaults to None.

elevation_maskArrayWUnits or float, optional

Default minimum elevation angle for ground-station observers, an ArrayWUnits angle such as ArrayWUnits(10, deg). A bare number is degrees, and one that could be radians is refused (see resolve_elevation_mask()). Defaults to 10.0 deg.

frameFrame, optional

Frame in which the measurements are computed. Defaults to J2000.

noisybool, optional

Whether the generated observations carry Gaussian noise drawn from each model’s sigma. Defaults to False.

output_dirstr, optional

Folder that receives the measurement files. None lets each model pick data/measurements/radiometric or data/measurements/optical from its file name. Defaults to None.

fmt{“json”, “pickle”}, optional

On-disk format of the measurement files. Defaults to "json".

pass_gapArrayWUnits, optional

Default gap between consecutive visible epochs that starts a new tracking pass, an ArrayWUnits time. None uses one and a half cadences of each request. Defaults to None.

Examples

import scarabaeus as scb

km, sec, minute, hr, Hz = scb.Units.get_units(["km", "sec", "min", "hr", "Hz"])

# Defaults shared by the requests below; every request may override them
scheduler = scb.MeasurementScheduler(
    target=Orbiter, elevation_mask=15.0, noisy=True
)

# Range from Goldstone every 10 min over two days, Doppler from Madrid
# every minute over one pass, OpNav of the Moon every hour over a week:
# three windows, three cadences, one scheduler
range_dss14 = scheduler.schedule(
    "DSS-14", "RangeIdeal", sigma=scb.ArrayWUnits(1e-3, km),
    start="2029 APR 01 00:00:00", end="2029 APR 03 00:00:00",
    cadence=scb.ArrayWUnits(10, minute),
)
doppler_dss63 = scheduler.schedule(
    "DSS-63", "DopplerIdeal", sigma=scb.ArrayWUnits(5e-3, Hz),
    start="2029 APR 01 20:00:00", end="2029 APR 02 04:00:00",
    cadence=scb.ArrayWUnits(1, minute),
    antenna_name="HGA", doppler_transmit_frequency=scb.ArrayWUnits(7.2e9, Hz),
)
opnav = scheduler.schedule(
    camera, "CentroidingIdeal", target=scb.Body("MOON"),
    sigma=scb.ArrayWUnits([0.5, 0.5], None),
    start="2029 APR 01 00:00:00", end="2029 APR 08 00:00:00",
    cadence=scb.ArrayWUnits(1, hr),
)

# Recurring windows: one Goldstone pass every Monday for a month,
# Canberra twice a day, five OpNav images a minute apart every 6 h
weekly = scheduler.schedule(
    "DSS-14", "RangeIdeal", sigma=scb.ArrayWUnits(1e-3, km),
    start="2029 APR 01", end="2029 MAY 01", cadence=scb.ArrayWUnits(10, minute),
    weekdays="Mon", passes_per_day=1,
)
twice_daily = scheduler.schedule(
    "DSS-43", "RangeRateIdeal", sigma=scb.ArrayWUnits(1e-7, km / sec),
    start="2029 APR 01", end="2029 MAY 01", cadence=scb.ArrayWUnits(1, minute),
    hours="02:00-06:00, 14:00-18:00",
)
batches = scheduler.schedule(
    camera, "CentroidingIdeal", target=scb.Body("MOON"),
    sigma=scb.ArrayWUnits([0.5, 0.5], None),
    start="2029 APR 01", end="2029 APR 08", cadence=scb.ArrayWUnits(1, minute),
    pass_cadence=scb.ArrayWUnits(6, hr), pass_duration=scb.ArrayWUnits(5, minute),
)

# Or the whole plan at once
measurements = scheduler.schedule_many([
    ("DSS-14", "RangeIdeal", {"sigma": ..., "cadence": scb.ArrayWUnits(10, minute)}),
    ("DSS-63", "DopplerIdeal",
     {"sigma": ..., "cadence": scb.ArrayWUnits(1, minute), "antenna_name": "HGA", ...}),
    (camera, "CentroidingIdeal",
     {"target": scb.Body("MOON"), "sigma": ..., "cadence": scb.ArrayWUnits(1, hr)}),
], start="2029 APR 01 00:00:00", end="2029 APR 03 00:00:00")

# Everything a filter needs
measurements = scb.MeasurementSpec.many(range_dss14, doppler_dss63, opnav)
range_dss14.model                                  # the RangeIdeal object
scheduler.scheduled["DSS-14 RangeIdeal"].epochs    # the visible epochs
scheduler.scheduled["DSS-14 RangeIdeal"].window    # its start / end / cadence / grid

static build_epochs(start: EpochArray | float, end: EpochArray | float, cadence: ArrayWUnits | float, pass_cadence: ArrayWUnits | float = None, pass_duration: ArrayWUnits | float = None, pass_offset: ArrayWUnits | float = 0.0, edge_tolerance: ArrayWUnits | float = None) → EpochArray#

Build the half-open epoch grid [start, end) at a fixed cadence.

With pass_cadence the grid is cut into slots [s_k, s_k + pass_duration), s_k = start + pass_offset + k * pass_cadence, each sampled from its own start at the cadence (so pass_cadence need not be a multiple of the cadence).

Parameters:
startEpochArray or float

First epoch: an EpochArray (its first epoch) or TDB seconds past J2000. Calendar strings and dates work as for the scheduler’s start.

endEpochArray or float

End of the grid (excluded), same conventions as start; an EpochArray is taken at its last epoch.

cadenceArrayWUnits or float

Spacing between epochs, an ArrayWUnits time such as ArrayWUnits(1, min). A bare number is seconds.

pass_cadenceArrayWUnits or float, optional

Time between the starts of two slots (bare number: seconds). None is one slot over the whole span.

pass_durationArrayWUnits or float, optional

Length of each slot (bare number: seconds); required with pass_cadence.

pass_offsetArrayWUnits or float, optional
