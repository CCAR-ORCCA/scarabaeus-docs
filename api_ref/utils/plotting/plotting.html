Plotting#

class Plotting#

Bases: object

Collection of standardised plotting utilities for Scarabaeus output data.

Provides methods to visualise OD solutions, trajectories, residuals, covariance ellipses, B-plane maps, and more. All methods apply a consistent style defined in set_custom_styling().

static plot_corner(samples, labels=None, mean=None, covariance=None, truths=None, indices=None, n_sigma=(1, 2, 3), title=None, **corner_kwargs)#

Corner plot of posterior samples, optionally against a Gaussian.

Every pair of dimensions gets a 2-D histogram with contours, and every dimension a marginal histogram, through corner.corner(). The contours enclose the probability a 2-D Gaussian holds within \(n\) standard deviations, \(1 - e^{-n^2/2}\), so with covariance the overlaid \(n\)-sigma ellipses coincide with them when the samples are Gaussian.

Parameters:
samplesMonteCarloSamples or array_like

Samples, e.g. MCMC.samples, or an array of shape (n_samples, n_dimensions). The weights and labels of a MonteCarloSamples are used.

labelssequence of str, optional

Name of each dimension of samples. Defaults to the labels of a MonteCarloSamples, otherwise none.

meanarray_like, optional

Centre of the Gaussian overlay, shape (n_dimensions,). Defaults to the weighted sample mean when covariance is given.

covariancearray_like, optional

Covariance of the Gaussian overlay (e.g. the filter’s), shape (n_dimensions, n_dimensions). Its n_sigma ellipses are drawn on the pairs and its density on the marginals. Defaults to no overlay.

truthsarray_like, optional

Reference value of each dimension, marked by lines. Defaults to none.

indicessequence of int, optional

Dimensions to plot. Defaults to all.

n_sigmasequence of float, optional

Contour and ellipse levels, in standard deviations. Defaults to (1, 2, 3).

titlestr, optional

Figure title. Defaults to none.

**corner_kwargs

Passed to corner.corner() (e.g. bins, smooth, show_titles, quantiles, fig).

Returns:
matplotlib.figure.Figure

The corner plot.

Raises:
CornerSamplesError

If samples is not a 2-D array with at least two samples, or indices picks dimensions it does not have.

CornerOverlayError

If labels, truths, mean or covariance does not match the dimensions of samples.

Examples

>>> solution = scb.MCMC(lsb).sample(seed=0)
>>> fig = scb.Plotting.plot_corner(
...     solution.filter.samples,
...     covariance=lsb_solution.covariance_est[0],
... )

Plot the 1-sigma (the square root of the covariance diagonal) of every state component over time, from JSON.

One line per state-covariance column, drawn against timeline_epochs (the deviation/covariance grid), labelled from the leg metadata where available. Sequence leg boundaries are marked. Which iteration to plot for multi-iteration files. Defaults to "final".

use_smoothedbool, optional

time_unit{“s”, “min”, “hr”, “day”}, optional

Units for the elapsed-time x-axis. Defaults to "hr".

log_scalebool, optional

Use a logarithmic y-axis (recommended for mixed-unit sigmas). Defaults to True.

save_dir, save_namestr, optional

If both given, the figure is written via save_plot().

static plot_residuals_json(json_path, iteration: str = 'final', kind: str = 'both', weighted: bool = False, n_sigma: float = 3.0, time_unit: str = 'hr', save_dir: str = None, save_name: str = None, show: bool = False)#

Plot prefit/postfit residuals directly from a solution JSON file.

One stacked subplot per dataset (measurement type). Each residual is plotted against its reception epoch from the per-entry time tag ([residual, sigma, epoch]) written by SolutionOD; older files without the tag fall back to the measurement index. Per-group RMS and count are shown in the legend, n_sigma reference lines are drawn, and sequence leg boundaries are marked.

Parameters:
json_pathstr or path-like

Path to a SolutionOD JSON file.

iterationstr, optional

Which iteration to plot for multi-iteration files ("iter_1" is the raw first pass, "final" the converged solution). Defaults to "final".

kind{“both”, “prefit”, “postfit”}, optional

Which residual set(s) to draw. Defaults to "both".

weightedbool, optional

If True, plot residual / sigma (dimensionless); the n_sigma lines become flat at plus and minus n_sigma. Otherwise plot raw residuals with an envelope of plus and minus n_sigma * sigma. Defaults to False.

n_sigmafloat, optional

Multiplier for the sigma reference lines. Defaults to 3.

time_unit{“s”, “min”, “hr”, “day”}, optional

Units for the elapsed-time x-axis. Defaults to "hr".

save_dir, save_namestr, optional

If both given, the figure is written via save_plot().

showbool, optional

Display the figure. Defaults to False.

Returns:

plot_media_coverage(type: str = 'tropo')#

Plot DSN coverage intervals (in Ephemeris Time) from a media correction JSON file.

This function is designed to handle both iono and tropo files, which share the same structure but differ in the top-level dictionary key (aux_iono or aux_tropo).

Parameters:
json_pathstr

Path to the JSON file containing the media corrections (iono or tropo).

typestr, optional

Type of file to process, either ‘iono’ or ‘tropo’. The function will look for the corresponding key in the JSON (aux_iono or aux_tropo). Default is ‘tropo’.

Notes

The expected JSON has the following fields under the block aux_type: "start_day", "start_time", "end_day", "end_time" (all lists of strings), and "dsn" (list of DSN identifiers, e.g. "C10", "C40").

To compute the CSP UTC day-time to ET conversion, the _csp_time_to_et method is used internally and requires a leapsecond kernel loaded in the script.

Examples

>>> plot_media_coverage("orex_2018_iono.json", type="iono")
>>> plot_media_coverage("orex_2018_tropo.json", type="tropo")
