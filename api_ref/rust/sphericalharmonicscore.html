SphericalHarmonicsCore#

class SphericalHarmonicsCore(order: int, r_ref: float)#

Bases: object

Body-fixed spherical-harmonics kernels (normalized coefficients only).

Computational core of SphericalHarmonicsGravity: the normalized Cunningham B_nm recurrence, the acceleration sum, the position Jacobian, and the partials with respect to the C_nm / S_nm coefficients. SPICE rotations, ephemerides, and estimated-parameter handling stay on the Python side, which passes in the body-fixed position and the effective mu / C_nm / S_nm for each evaluation.

With \(R\) = r_ref and fully normalized coefficients, the potential is [1]

\[U = \frac{\mu}{r} \sum_{n=0}^{N} \sum_{m=0}^{n} \left(\frac{R}{r}\right)^{n} \bar{P}_{nm}(\sin\phi) \left[\bar{C}_{nm} \cos m\lambda + \bar{S}_{nm} \sin m\lambda\right] = \frac{\mu}{R} \sum_{n=0}^{N} \sum_{m=0}^{n} \left(\bar{C}_{nm} V_{nm} + \bar{S}_{nm} W_{nm}\right),\]

in terms of the solid harmonics

\[B_{nm} = V_{nm} + i\,W_{nm} = \left(\frac{R}{r}\right)^{n+1} \bar{P}_{nm}(\sin\phi)\, e^{i m \lambda}.\]

These are built from \(B_{00} = R/r\) with Cartesian recurrences [2], so there are no angles and no singularity at the poles:

\[\begin{split}B_{mm} &= \sqrt{\frac{(1+\delta_{1m})(2m+1)}{2m}}\, \frac{R}{r}\,\frac{x + i y}{r}\, B_{m-1,m-1}, \\ B_{nm} &= \sqrt{\frac{4n^2-1}{n^2-m^2}}\, \frac{R}{r}\,\frac{z}{r}\, B_{n-1,m} - \sqrt{\frac{(2n+1)\left[(n-1)^2-m^2\right]}{(2n-3)(n^2-m^2)}} \left(\frac{R}{r}\right)^2 B_{n-2,m}.\end{split}\]

The body-fixed acceleration is [3]

\[\begin{split}\ddot{x} &= \frac{\mu}{R^2} \sum_{n,m} \left[ -g_1 \left(\bar{C}_{nm} V_{n+1,m+1} + \bar{S}_{nm} W_{n+1,m+1}\right) + g_2 \left(\bar{C}_{nm} V_{n+1,m-1} + \bar{S}_{nm} W_{n+1,m-1}\right)\right], \\ \ddot{y} &= \frac{\mu}{R^2} \sum_{n,m} \left[ g_1 \left(-\bar{C}_{nm} W_{n+1,m+1} + \bar{S}_{nm} V_{n+1,m+1}\right) + g_2 \left(-\bar{C}_{nm} W_{n+1,m-1} + \bar{S}_{nm} V_{n+1,m-1}\right)\right], \\ \ddot{z} &= \frac{\mu}{R^2} \sum_{n,m} g_3 \left(\bar{C}_{nm} V_{n+1,m} + \bar{S}_{nm} W_{n+1,m}\right),\end{split}\]

where the \(g_2\) terms are absent for \(m = 0\) and

\[\begin{split}g_1 &= \frac{1+\delta_{0m}}{2} \sqrt{\frac{(2-\delta_{0m})(2n+1)(n+m+2)(n+m+1)}{2(2n+3)}}, \\ g_2 &= \frac{1}{2} \sqrt{\frac{(2-\delta_{0m})(2n+1)(n-m+2)(n-m+1)}{(2-\delta_{1m})(2n+3)}}, \\ g_3 &= -\sqrt{\frac{(2n+1)(n+m+1)(n-m+1)}{2n+3}}.\end{split}\]

The acceleration is linear in \(\bar{C}_{nm}\) and \(\bar{S}_{nm}\), so their partials are the bracketed factors. The position Jacobian differentiates once more, which carries the recurrence to degree \(N + 2\). The _rf methods rotate the body-fixed results with the body-fixed to reference rotation \(\mathbf{R}\): \(\mathbf{a}_{rf} = \mathbf{R}\,\mathbf{a}\) and \(\mathbf{J}_{rf} = \mathbf{R}\,\mathbf{J}\,\mathbf{R}^T\).
